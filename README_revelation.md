# EBand

这是一个计步器web、Android应用，你的步数会帮助一朵虚拟的花朵成长。

    - 10000-19999步：郁金香（🌷）

## 安装与首次启动

1. 从 [Releases](https://github.com/bartek537/forest/releases) 下载最新的 **稳定版** 应用程序二进制文件（.apk 文件）。
2. 点击下载的文件，如果出现提示，暂时 **允许来自未知来源的安装**（安装后将其关闭）。
3. 在某些设备上，您可能会遇到 Play Protect 警告，但请不要担心——该应用是安全的，并且是开源的。我只是一个未经认证的开发者。
4. 点击“安装”并等待应用安装完成。
5. 现在您可以开始使用了 🚀。
6. **测试:**
    - 如果使用模拟器，您可以通过扩展控件来模拟行走或移动，观察步数变化。
    - 如果使用真实设备，只需携带设备行走即可看到步数更新。
    - 在开发（Debug）版本中，页面上会添加“Walker”和“重置”按钮。点击“walk”按钮模拟行走，每按一下增长500步。点击“重置”按钮，步数归零。

> [!CAUTION]
> 在大多数设备上，您需要 **关闭应用的电池优化**，以便应用准确计数步数。Forest 使用最少的电量，不会影响您的电池续航。
>
> - 运行 MIUI 14 的小米设备
>     1. 前往 设置 > 应用 > 应用管理 > Forest > 省电策略。
>     2. 选择“无限制”。
>
> - 运行 Lineage OS 22.2 的设备
>     1. 前往 设置 > 应用 > 所有应用 > Forest > 应用电池使用情况 > 允许后台使用（点击设置名称进入另一个菜单）。
>     2. 启用“允许后台使用”。
>     3. 将电池优化更改为“不受限制”。
