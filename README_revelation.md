# EBand

这是一个计步器web、Android应用，你的步数会帮助一朵虚拟的花朵成长。

## 在线体验

[**立即体验 EBand**](https://qcgm1978.github.io/web_Eband/) 👈 点击链接在线访问

## 功能

- 记录每日步数。
- 根据步数，虚拟的花朵会经历不同的成长阶段：
    - 0-2999步：花苞（🌱）
    - 3000-5999步：满天星（✨）
    - 6000-9999步：数字薄荷（🌿）
    - 10000-19999步：秋菊（🏵️）
    - 20000+步：完成！
- 每种花朵在解锁时都会有“绽放”动画，并在其生长阶段内随着步数持续变大。

## 如何测试

1. 在Android设备或模拟器上运行此应用。
2. 启动应用，并在提示时授予“身体传感器”和“活动识别”权限。
3. 如果使用模拟器，您可以通过扩展控件来模拟行走或移动，观察步数变化。
4. 如果使用真实设备，只需携带设备行走即可看到步数更新。
5. 如果是开发环境页面上添加Walker和重置按钮，可以点击walk按钮模拟行走。每按一下增长500步。点击重置按钮，步数归零。
